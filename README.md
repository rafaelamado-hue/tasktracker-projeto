# TaskTracker - Gerenciador de Tarefas CLI

Aplicação em linha de comando (CLI) desenvolvida em Python 3 para gerenciamento de tarefas pessoais e de equipe, com suporte a validação de dados, priorização e prazos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Versionamento:** Git & GitHub
